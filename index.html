지역별 환경보건 취약지수 시각화 맵

행정동별 지표를 선택해 단계형 색상 지도로 확인합니다. 모든 수치는 시연용 가상 데이터이며, 행정동명은 ADM 코드로 비식별 표기됩니다.

변수
정규화
OFF
※ 정규화 ON: 1~10 점수로 표시
※ 정규화 OFF: 원본 데이터 값 그대로 표시
영역
※ 각 영역별 변수들의 평균 점수
※ 소수점 한자리로 표시(반올림)
종합
※ 산출식 로딩 중…
※ 녹색(낮음) → 황색(중간) → 적색(높음)
유의
1. 가상 데이터
본 화면은 포트폴리오 공개용으로, 모든 지표 값은 실제 자료가 아닌 무작위로 생성한 가상 데이터입니다. 지도 경계만 실제 행정동 형상을 사용했으며, 표시되는 수치·순위는 실제 지역 현황과 무관합니다.
2. 행정동명 → ADM 코드 표기
행정동명 대신 ADM-01 ~ ADM-55 코드로 표기했습니다. 코드는 데이터 수록 순서로 부여한 고정 일련번호이며, 취약지수 순위·지역 위치와는 무관합니다.
3. 5개 영역 중 3개만 사용
원 모델은 환경압력·환경수준·환경보건수준·민감인구·사회경제적수준 5개 영역이나, 이 버전은 비공개 자료인 환경수준·환경보건수준(환경상태 블록)을 제외한 3개 영역만 사용합니다. 산출식은 결측 블록을 0으로 곱하지 않고 항 자체를 생략하도록 재구성했습니다. 따라서 원 모델 결과와 수치·순위가 다르며, 구동 방식 시연용으로만 보시기 바랍니다.
4. 상대지수
취약지수는 55개 행정동 내 상대 비교값(0~100)입니다. 최저 동이 0, 최고 동이 100이 되도록 재조정한 값이라 절대적 위험 수준이나 타 지역·타 연도와의 비교에는 쓸 수 없습니다.

데이터 분석 차트

차트 라벨 ADM 코드 (행정동명 비식별)

※ 선택 행정동(ADM 코드)의 세부변수별 정규화 점수(1~10). 오른쪽(빨강)=취약성 가중(부호 +), 왼쪽(초록)=취약성 완화(부호 −). 막대가 길수록 그 방향으로의 영향이 큼.

※ 두 행정동(ADM 코드)의 영역 점수를 정규화(1~10)하여 그룹 바 차트로 비교합니다. 현재 3개 영역만 표시됩니다.

※ 선택 지표 기준 상위·하위 행정동을 수평 바 차트로 표시합니다. 붉을수록 높은 값, 초록일수록 낮은 값입니다.

※ ADM 코드 × 영역 + 종합취약지수(0~100) 히트맵. 좌우·상하 스크롤 가능합니다. 초록→황→적으로 갈수록 높은 수치입니다.
